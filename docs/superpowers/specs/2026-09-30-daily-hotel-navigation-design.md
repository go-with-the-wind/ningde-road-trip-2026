# 每日酒店与高德导航设计

**状态：** 用户已授权自行决定并直接发布，不等待交互式设计确认。

## 目标

在五日路书中为每个需要过夜的日期提供酒店管理卡。使用者可在页面内查询并选择高德 POI，保存酒店名称、地址、电话和导航坐标；随后可一键发起高德驾车导航，并在页面地图中定位酒店。

## 范围

- 覆盖 D1—D4 四个住宿夜：云顶、屏南、周宁第 1 晚、周宁第 2 晚。
- 保留已核验的 D1 默认酒店“永泰云顶蚂蚁窝蛋居民宿”及其高德 POI 坐标。
- D2、D3、D4 默认未填写；D4 提供“沿用 D3 酒店”快捷操作。
- 高德 JS API PlaceSearch 用于查询和选择 POI；选中后才提供精确的导航与地图定位。
- 酒店配置保存在浏览器 `localStorage` 中；页面刷新、关闭后仍在同一浏览器保留。
- 使用者可以编辑或清除每个住宿夜的酒店。

## 非目标

- 不引入服务器、数据库、用户账户或 GitHub OAuth。
- 不在浏览器中保存 GitHub token，也不尝试从页面提交用户输入到 GitHub。
- 不自动把模糊名称、地址或未选 POI 当成精确停车入口。
- 不修改行程日期、路线、已有高德行车路线或天气逻辑。

## 用户流程

1. 使用者在 D1—D4 行程卡中看到“今晚住宿”卡。
2. 已有酒店时，卡片显示酒店名称、地址与“高德导航”“地图定位”“编辑”操作；无酒店时只显示“添加酒店”。
3. 点击“添加酒店”或“编辑”，打开单一原生 `<dialog>`：酒店名称、城市、地址备注可编辑。
4. 点击“查询高德 POI”后，PlaceSearch 返回候选项；使用者必须选择一条候选 POI 才能保存为可精确导航的酒店。
5. 保存后，将 POI ID、名称、地址、GCJ-02 坐标与高德登记电话写入 `localStorage` 并重新渲染所有酒店卡与酒店地图标记。
6. 当 D4 尚未设置时，使用者可一键复制 D3 的酒店配置；之后仍可单独编辑。
7. 点击“高德导航”时，由 POI 的 GCJ-02 经度、纬度和名称组成 URI；点击“地图定位”时，地图居中并弹出酒店信息。

## 数据模型

```js
{
  version: 1,
  nights: {
    d1: { day: 'D1', date: '2026-10-01', city: '永泰', name, address, poiId, lng, lat, tel, note },
    d2: { day: 'D2', date: '2026-10-02', city: '屏南', name, address, poiId, lng, lat, tel, note },
    d3: { day: 'D3', date: '2026-10-03', city: '周宁', name, address, poiId, lng, lat, tel, note },
    d4: { day: 'D4', date: '2026-10-04', city: '周宁', name, address, poiId, lng, lat, tel, note }
  }
}
```

- `lng`、`lat` 为高德 PlaceSearch 直接返回的 GCJ-02 坐标，专用于高德 URI 与地图标记。
- 现有路线 `tripStops` 仍采用 WGS84，由既有转换函数处理；酒店标记不写入其路线数据，避免用户酒店改变四段主路线。
- `note` 为可选的用户可见备注，例如“停车以订单为准”。

## 界面与可访问性

- 酒店卡使用现有 `.day-actions` 与按钮视觉体系，额外采用一张浅色信息卡，不改变五日行程的展开/收起模式。
- 使用原生 `<dialog>`，保留默认 Esc 关闭与焦点管理；提供明确的关闭按钮。
- 查询状态、无结果和存储错误使用 `aria-live="polite"`。
- 操作按钮及候选 POI 使用可键盘访问的 `<button>`。
- “高德导航”只在酒店具有有效经纬度时显示；否则只显示编辑操作，杜绝假导航。

## 失败处理与边界

- `localStorage` 不可用或内容损坏：显示说明，回退到 D1 默认酒店和空白 D2—D4；不让页面脚本中断。
- 高德 API 或 PlaceSearch 未加载：保留表单和保存功能，但显示“暂不能查询 POI”；用户不能生成精确导航，待地图恢复后重新查询。
- 搜索无结果：不自动挑选，不保存为 POI，提示修改酒店名称或城市。
- 高德返回电话：标为“高德登记电话”，不暗示为酒店前台。
- 当前地址或名称与实际停车入口可能不同：卡片明确提示“最终入口和停车以订单联系人为准”。
